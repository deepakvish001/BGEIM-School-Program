CODE THE VOICE

The 3-Day AI Voice Agent Bootcamp
Build an AI that listens, thinks and talks back.

Siri, Alexa and Google Assistant were built by large teams of engineers. In three days, your students will build their own.

It hears a question, thinks with a real large language model, pulls live data from the internet and answers out loud, in English or Hindi. There are no ready-made apps and no drag-and-drop blocks. 2. Why This Bootcamp

  • Voice AI is where the industry is heading. Banks, hospitals, airlines and online stores now use AI agents that talk to customers. Students build a small version of the same technology.
  • It shows the whole picture. Students use AI every day but rarely see how an AI product is put together. Building an agent from start to finish covers speech, language models, APIs, prompts and safety in one project.
  • It stretches students who can already code. The project goes well beyond classroom exercises, and the finished agent can be shown at science exhibitions, hackathons and in college applications.
  • It supports the school curriculum. CBSE offers Artificial Intelligence as a subject. The bootcamp turns that theory into working practice.

3. What Students Will Build

Every team builds a voice AI agent that runs in the web browser. It follows the same four-step design used in commercial voice agents:

LISTENSpeech-to-text with the Web Speech API
THINKJavaScript rules and a large language model (Google Gemini)
ACTLive data from web APIs, such as weather and Wikipedia
SPEAKText-to-speech with the Speech Synthesis API

The language model is reached through BGIEM’s lab server, so students never handle API keys.

On the last day, each team turns its agent into a product for a real purpose of its own choice, for example:

  • a school helpdesk that answers questions about timings, events and rules;
  • an exam revision tutor that asks questions and explains answers;
  • a city guide for Jabalpur that talks about places, weather and history;
  • a career counsellor that explains courses and career paths.

5. Learning Outcomes

By the end of the bootcamp, students will be able to:

  1. explain how a voice AI agent works, from speech recognition to the spoken reply;
  2. use the browser’s speech recognition and speech synthesis APIs in JavaScript;
  3. call web APIs, work with JSON data and write asynchronous code;
  4. connect an application to a large language model and control it with system prompts and guardrails;
  5. add agent behaviour such as tool selection, memory and interruption handling;
  6. plan, test and present a software product as a team.

6. What Students Take Home

  • The complete source code of their agent, with comments.
  • Their agent published on the BGIEM showcase page for one month, so that it opens on any phone.
  • A bootcamp handbook that explains every level step by step.
  • A certificate of completion from BGIEM. The top three teams also receive awards.
  • Four weeks of online doubt support through a Google Classroom managed by the school.

9. Student Safety and Data Privacy

  • No student creates an account on any AI service, and no API key is shared with students.
  • The AI lab server has usage limits and logs no personal data.
  • Every agent has guardrails in its system prompt, so that it stays on its topic and refuses unsafe requests.
  • Speech recognition in Chrome is processed by Google’s online speech service, so students are told not to share personal information with their agents.
  • Photographs are taken only as per the school’s policy.
