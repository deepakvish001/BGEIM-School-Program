# BGIEM School Program

Course curriculum for the **AI Awareness & Hands-on Workshop for School Students**, run in schools by Baderia Global Institute of Engineering & Management, Jabalpur.

- **`BGIEM_AI_Workshop_Course_Curriculum.pdf`**: the final document, ready to submit (about the programme, objectives, nine modules with topics, concepts, examples and tools, course outcomes, tools covered)
- `source/course-curriculum.html`: the editable source of the PDF
- `assets/`: college logo and font (Source Serif 4, SIL Open Font License)

## Rebuilding the PDF

After editing `source/course-curriculum.html`:

```bash
npm install
npm run build
```

This needs Node.js and Playwright (Chromium).
